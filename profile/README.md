## 👋 hckr - Empowering Developers with Powerful Utilities

hckr is a community-owned collection of developer tools and utilities designed to streamline your development workflow. Whether through our command-line interface or browser extension, hckr helps developers accomplish tasks efficiently and with ease.

### 🌟 What is hckr?

hckr is focused on facilitating the development of applications by helping developers accomplish required tasks through utilities specifically designed to enhance efficiency and productivity. We believe in empowering developers with tools that just work.

### 🐢 🌎 📚 Our Ecosystem

- **hckr CLI** - Command line utility for developers
- **hckr Browser Extension** - A community-owned Chrome browser extension for developers

## Installation

### hckr CLI
* using HomeBrew
```console
brew tap hckr-cli/tap
brew install hckr
```
* using pip
```console
pip install hckr
```

### hckr Browser Extension
Available in the [Chrome Web Store](https://chromewebstore.google.com/)
